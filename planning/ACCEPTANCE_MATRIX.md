   state. Release the updated runtime through
   the immutable artifact gates before claiming released-interface consumption.
2. Author and independently qualify real fresh private coding contracts/fixtures,
   bind all practical families through the generic installed adapter and approve
   a new immutable course version. Preserve old evaluator versions and enrollment
   pins. Verify wrong-first, help/repeat, exhausted-bank and cap cases through the
   private browser path; then run all56episodes with separate test learners.
3. Implement the supervisor's bounded structured decision/tool loop. Start with
   scoped history retrieval, learner-model proposals, reviewed fresh checks and
   verified teaching/visual changes; then dispatch real research/media work. Give
   every call a stable operation ID, current evidence/policy/plan fences, a cost
   reservation, finite attempts and a learner-visible receipt. No tool can change
   mastery, the course goal, required grading criteria or paid ceilings silently.
4. Deliver credential/model/budget setup and debug/context GUI before asking the
   user to configure Google. No credentials in chat or browser bundles, no paid
   calls from an unanswered default. Run live provider acceptance only after the
   user sets secure credentials and a spending allowance.
5. Close the remaining policy/privacy/operations/multiplatform gates and perform
   the complete v0.8 audit and actual POC walkthrough. Do not mark the goal complete
   merely because the current module/CI matrix is green.
